vvPet 0.1.43 · 2026-11-25

本轮把桌宠窗口的缩放改回「以中心为基准」，让回复气泡按内容伸缩，让陪伴对话可以直接加待办、设提醒和读简报；同时修正 Outlook 邮件时间属性的读取方式，并把 Agent 的工具边界与报错提示说清楚。

- 桌宠缩放改为**以窗口中心为基准**：第一次缩放前捕获中心位置，缩放后按实际窗口尺寸回到同一中心；缩放与拖拽交错时用 `petResizeEpoch` 丢弃过期写回，不再出现「缩放后桌宠跑到角落」。
- 缩放作用在新的 `.pet-stage` 容器上（`transform-origin: center center`），贴纸与墨迹保持中心对齐；圆环菜单不再被一起缩放。拖拽边界按实际窗口外框计算，缩放后的桌宠不会被拖出屏幕。
- 气泡高度按回复内容自适应（108–280px），原生 `set_pet_quick_view` 接受实测高度并夹在有效区间内；迟到的测量不会重新打开已经被用户关掉的气泡。短回复 7 秒收起，长回复最多 20 秒，鼠标悬停时暂停收起计时。
- 新增 `features/companion/actions.ts`：一句话里的「加待办」「多久后提醒」「今天简报」可以直接执行并给出回执，不必先去点按钮。意图判断有本地规则与模型分类两层兜底，「今日热点 / 新闻」明确归为闲聊，不会误触发简报。
- 问「我有哪些待办」不再触发联网搜索（`isOwnTaskQuestion`），避免用通用文章掩盖真实待办；陪伴提示词补上 `localDate` 与 `dueToday`，只有列表为空才能说没有待办。
- `VT_DATE` 变体按日期读取（`variant_date_f64`），修复时间属性类型不匹配导致邮件与日历提醒被整条跳过。缺少 `ReceivedTime` 的邮件不再被丢弃，未读计数改用收件箱 `UnreadItemCount`，不再被 20 条列表上限截断。
- 邮箱页区分 Outlook 本机邮件与 IMAP 缓存条目（`isImapCachedEntry`），「最近邮件」标题显示当前账号地址。
- OpenAI 兼容 Agent 的系统提示新增**工具使用边界**：本机没有联网搜索工具，同一工具或同一类查询连续失败两次即停止重试并说明原因。「内容审核拦截（1026）」与「工具步骤预算用完」单独提示，不再把用户引向检查 API Key 或 Base URL。
- 今日待办列表的「完成」改为独立按钮，点选任务不再自动开始番茄钟。
- 桌宠轻交互的停止按钮现在会真正中止正在进行的陪伴回复（按流 id 调用 `cancel_chat_stream`）。

验证：394 项前端契约测试通过；356 项原生测试通过、17 项需外部资源的测试默认忽略；Vue/TypeScript 检查与生产前端构建通过；版本统一为 0.1.43。未使用 Computer Use 或 Playwright。

仍待本机验收：缩放后桌宠是否仍停在原位、气泡高度与收起时机、待办与提醒动作的真实执行结果、Outlook 邮件时间的显示。

升级保留本机模型、账号连接、录音与文档。轻交互的两种模式（陪伴 / 对话）已合并为统一的陪伴回复气泡，v0.1.42 写入的本地键 `vv.pet.quick.mode` 不再被读取，残留该键不影响使用，删除即可。
