vvPet 0.1.40 · 2026-11-23

本轮把 Agent 从「会聊天」推向「有规则、有办公数据」，同时收紧运行时权限并清理依赖与素材。

- 助手规则（AGENT.md）：应用数据根目录下的 `AGENT.md` 与设置面板双向同步，每次对话作为系统规则注入；工作区内存在 `AGENT.md` / `AGENTS.md` 时自动叠加。优先级为「系统安全边界 > 工作区规则 > 全局规则」，全局上限 4000 字、工作区上限 2000 字。规则读取失败不会阻断对话。
- Agent 办公工具：新增 5 个只读工具——`search_knowledge_base`（本地知识库，SQLite FTS5 全文与 BGE 语义向量混合检索，返回片段、路径与行号）、`query_office_mails`（Outlook 与 QQ/163 邮件，只读）、`query_calendar_events`、`list_pomodoro_todos`、`list_meeting_records`。写操作只保留 `add_pomodoro_todo` 一项；工具按 Agent 模式（research / office / workspace）分别注册，越权工具在注册阶段即被过滤。
- 权限收紧：asset 协议作用域从脚手架默认的全盘通配 `**` 收窄为 `$APPDATA/**`、`$LOCALAPPDATA/**`、`$RESOURCE/**`。新增外部 HTTP 地址校验、剪贴板非文本内容检测、更新包文件名清洗与 MCP 宿主运行时探测。
- 运行时稳健：Python 技能执行改为流式读取输出、120 秒超时并纳入 Job Object 进程组，取消或超时能真正终止子进程；BGE 会话空闲后可卸载；技能输入文件哈希改为流式计算，超过 8 MiB 不再全量读入内存，单次技能摘要最多处理 2048 个文件。
- 窗口与灵动岛：聊天窗口支持展开、收起与切换；窗口加载页与错误页新增关闭按钮，卡在加载阶段也能直接退回桌宠；新增「正在播放」读取与播放 / 暂停切换。
- 依赖瘦身：移除 `ndarray`、`rayon` 两个原生依赖与 `reqwest` 的 blocking 特性；移除未使用的 `playwright` 与 `translate.js` npm 依赖（划词翻译仍走 CDN 脚本），并新增 `npm test` 脚本。
- 资源：删除 5 张已无引用的旧图，新增 `AGENT.png` 与 `灵动岛.png`。

验证：351 项前端契约测试通过；344 项原生测试通过、17 项需外部资源的测试默认忽略；Vue/TypeScript 检查与生产前端构建通过；版本统一为 0.1.40。未使用 Computer Use 或 Playwright。

仍待本机验收：助手规则在真实对话中的生效效果、Agent 办公工具的真实调用与命中、跨窗口设置冲突、Python 技能取消与超时的真实行为、完整截图操作与音效听感。

升级保留本机模型、账号连接、录音与文档；新增的 `AGENT.md` 助手规则与应用数据同目录存放，删除该文件即可恢复默认规则。
