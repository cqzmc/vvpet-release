vvPet 0.1.44 · 2026-11-26

本轮把「今天」并进对话坞，补上单实例启动、待办日期时间选择、思考与加载动效，以及陪伴标签、邮箱未读与 Agent 批量文件预览。

- 新增 `single_instance`：二次启动时唤起已有聊天 / 桌宠窗口并退出新进程，避免多开。
- 侧栏移除独立「今天」页；`openDockToday` 把待办、简报与专注放进对话坞（Ctrl+2 / 命令面板仍可打开）。
- 新增 `TaskDatePicker` / `TaskTimePicker`：截止日期与提醒时间可点选，并支持今天 / 明天 / 下周一快捷项。
- 新增 `ThinkingOrb` 与 `ReplySpinner`：生成中展示思考耗时与加载指示。
- 对话与工作记录按安全 Markdown 渲染（`features/office/markdown.ts`），转义 HTML 并过滤不安全链接。
- 英文回复强制保留【心声】【回复】标签，解析同时兼容 heartbeat / reply 写法；主聊天、陪伴与快聊共用同一朗读通道。
- Outlook「最近邮件」只列收件箱，未读优先并显示未读圆点。
- 灵动岛在无默认天气时仍保留天气卡片；输入城市即可连接。
- Agent 新增批量重命名、整理文件的危险操作预览；`read_image_text` 在各模式注册为只读工具。
