vvPet 0.1.37 · 2026-11-16

本轮修复对话页“等整段出现”的流式问题，按模型修正每日简报的输出预算，并给陪伴页接入只读联网查询与灵动岛快捷入口。

- 真实流式输出：普通“对话”默认启用工具并走共用 Agent 分支，此前 OpenAI 兼容分支发送 `stream: false`、等待完整响应后才发给前端，JSON 计划分支同样等完整结果，前端另有逐字动画缓冲。现在请求并消费真实 SSE，收到正文片段立即交付前端，前端直接更新响应式消息并移除逐字定时器，结束时用完整答案校准。
- 工具与计划流：OpenAI 流按索引收集工具调用参数与思考元数据，参数完整且流正常结束后才进入原有解析、权限与确认流程，被截断的工具调用不执行；JSON 计划流只展示根级最终回答字段的文字，不展示协议 JSON 或嵌套工具参数，保留原有完整计划校验。
- 流解析健壮性：SSE 按完整字节行解码，处理中文与 Emoji 跨网络分片和多行数据，并兼容服务忽略流式参数直接返回单次 JSON 的情况。思考片段保存在独立字段，没有正文时显示“正在思考”；MiniMax 请求显式拆分思考与答案；停止生成后保留已收到的正文并拒收迟到事件。
- 简报按模型分配预算：此前简报请求使用 `Math.min(4096, ...)`，把包括用户配置的更大输出上限在内的请求统一压到最多 4096 Token，导致 MiniMax M3.1 Flash 在写出最终 JSON 前耗尽预算（返回 `finish_reason=length` 且答案为空）。现改为按模型选择生成参数：MiniMax M3.1 Flash 默认总输出预算 131072、简报专用推理等级使用 `low`，不修改普通聊天设置；用户已明确设置最大输出时遵循该上限并去掉额外截断；Agnes、其他模型和本地 GGUF 保持原有策略。
- 陪伴联网查询：陪伴页新增应用自有的只读查询，在模型请求前补充真实资料，只发送本轮查询词或天气城市，不发送记忆与办公聊天。联网模式可选“自动判断 / 每次搜索 / 关闭”，默认自动判断，按天气、新闻、查证、歌手等关键词触发。
- 查询数据源：必应搜索 RSS 提供通用网页摘要（最多 5 条并做关键词相关性筛选），百度实时热榜用于“今日热点”等宽泛问题，心知天气提供未来 3 天预报；必应新闻 RSS 在本机请求重定向至首页，未采用。查询在原生侧执行，固定使用公开服务并限制超时、响应大小与条目数量。
- 来源呈现：搜索资料作为不可信数据交给模型，提示模型区分摘要、热度和已核实事实，不把索引时间当作事件或文章发布时间；来源随对应回复保存，悬停消息出现“来源”入口，浮层脱离聊天滚动容器以免被裁切。旧数据库新增消息来源列与联网偏好列，旧聊天继续可读。
- 灵动岛与角色预设：灵动岛滚轮新增始终可发现的“开始专注”和“截图”卡片，轻展开增加下一张按钮与切换提示并支持左右方向键；温和自然、轻松活泼、理性清晰三个预设均完整填充性格、表达方式、兴趣与背景、示例对话并勾选角色感受，切换预设保留名称、用户称呼与回复语言等独立偏好。
- 截图音效：截图完成与添加截图使用 0.22 秒快门声，单独“另存为”保存使用 0.30 秒轻确认声；音效为项目内合成的 PCM WAV，嵌入程序并缓存播放，无第三方音频或在线请求，只有成功回执才会触发。
- 依赖：新增 `quick-xml` 用于流式与 RSS 解析。
