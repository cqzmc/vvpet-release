vvPet 0.1.33 · 2026-11-14

本轮整合桌宠轻交互、Agent 工作区、录制工作台与离线引擎。

- 聊天与模型：自适应气泡、编辑重发与复制反馈；三档授权、上下文估算/压缩、快捷命令；各模型连接和参数独立保存。
- 桌宠轻交互：白色短点贴近宠物，单行快聊、截图和有效提醒；修复输入无法打开、瞬时失焦及过期悬停计时器。
- Agent 与工作区：目录信任、文本与代码编辑、精确补丁、变更产物、备份恢复及有界程序执行。
- 录制工作台：一键录音、自动转写/纪要、真实电平和计时；长音频断点转写、转 MP4 进度/取消/续转，剪辑直接读取本机录制路径。
- 离线引擎：OCR/Kokoro 固定依赖、多源校验和实际调用验证；最多 3 文件并行下载，复用校验片段与已安装依赖。
- 界面精简：OCR 并入运行时、邮件开关移到系统设置；“更多”菜单改为独立浮层，修复无法展开。
- 每日简报：恢复打开主窗自动展示当天简报；缓存复用、失败反馈，建议行动可加入待办且不重复创建。
- 传文件仅保留微信；邮件判断统一使用当前模型，移除旧本地分类器及相关判断历史。

验证：295 项前端、293 项原生测试通过；类型、前端构建和资源目录验证通过。14 项需外部资源的原生测试默认忽略。未使用 Computer Use 或 Playwright，麦克风、多屏及真实网络体验仍由用户本机验收。

每日简报启用时，打开主窗会用当前模型汇总可读取的办公数据。远程模型会收到所需邮件、日历、聊天和待办摘要；可在系统设置关闭，或选择本地模型。邮件回复仅生成草稿，不自动发送。

升级保留本机模型、账号连接、录音与文档；旧分类器专属目录和判断历史按既定迁移清理。安装包不内置全部离线模型。原 README 海报保留，新版海报与说明同步更新。
