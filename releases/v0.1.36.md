vvPet 0.1.36 · 2026-11-15

本轮给陪伴页补上可编辑的角色设定、回答语言与交流风格，并新增陪伴专用语音朗读；同时修复 Edge 在线合成的握手与校验协议。

- 角色设定：陪伴对话顶部新增“角色设定”区域，可设置伙伴名称、用户称呼、性格、表达方式、兴趣背景与示例对话，支持换行，编辑区在对话区域内滚动。
- 性格预设：温和自然、轻松活泼、理性清晰三套预设可一键套用；套用时保留已有兴趣与示例对话，另提供独立的“重置角色”入口。
- 回复语言：可选跟随界面、固定中文、固定英文或中英对照，并独立持久化；英文回复使用英文篇幅约束，中英对照在一次请求内生成。
- 交流风格：自然交流、理性讨论、创意交流三种，作为角色表达的一部分参与生成。
- 角色感受：作为公开的角色表达与正文分开展示，默认关闭，与真实模型推理分开；陪伴模型推理开关继续关闭，精简本地模式使用有界角色核心且不显示角色感受。
- 语音朗读：陪伴页支持中文与英文分别朗读、朗读最新回复、固定短句试听，以及可选的自动朗读。自动朗读默认关闭，只朗读本页新生成并成功保存的回复，不播放历史记录、关心提示或角色感受，并尊重用户已经开始的手动朗读。
- 音色：陪伴使用独立的 Edge 合成入口，中文固定晓伊 `zh-CN-XiaoyiNeural`，英文固定 Ana `en-US-AnaNeural`；主聊天的音色配置继续使用其既有设置，两者互不影响。
- 原生合成修复：补齐必需的 WebSocket 握手头并适配当前 v2 校验协议，修复原先被服务返回 403 的朗读失败；未引入 Python 运行时或额外常驻服务。协议数字表、参考来源与许可说明见源码仓库 `docs/third-party/edge-tts-protocol.md`。
- 播放所有权：陪伴与主聊天共用一个扬声器，停止会取消原生合成、清理播放状态并丢弃迟到结果；网络失败时显示错误，不会自动改用其他声音冒充指定音色。
- 设置兼容性：陪伴设置写入新增的独立设置表，兼容旧数据；设置带独立版本号，旧窗口不会覆盖其他窗口已经保存的设置；人设或语言版本变化时停止过期生成，后续请求继续使用独立陪伴上下文。
- 记忆：召回不再用无关条目填满预算；“记住这句”只把用户消息放入编辑区，不自动保存，也不静默截断否定条件；删除记忆与清除原始聊天仍是两个独立操作。
- 界面细节：修正数字的语言分类，“专注 25 分钟”中的数字沿用句子语言；设置区图标为内联 Tabler Icons（MIT）。
- 仓库维护：移除已废弃的本地产物与过期文档（旧 PPT 生成脚本与其构建产物、展示站点的历史构建输出、过期演示稿与计划跟踪文件），展示站点源码保留。

验证：322 项前端契约测试通过；318 项原生测试通过、16 项需外部资源的测试默认忽略；Vue/TypeScript 检查与生产前端构建通过；版本统一为 0.1.36。未使用 Computer Use 或 Playwright。

仍待本机验收：角色设定的实际表达自然度、扬声器听感、跨窗口设置冲突的真实表现，以及自动朗读在多轮对话中的打断行为。角色感受的后台提醒、跨重启调度、休眠恢复补偿、连续语音与语音打断尚未实施。

升级保留本机模型、账号连接、录音与文档；陪伴设置写入新的独立设置表，与既有记忆、聊天记录互不影响。
